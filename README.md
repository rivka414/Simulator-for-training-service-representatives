# AI Voice Simulator - Training System

מערכת מתקדמת להכשרת נציגים המבוססת על בינה מלאכותית (AI), המאפשרת סימולציות קוליות בזמן אמת, ניתוח ביצועים אוטומטי וייעול משמעותי של תהליכי הלמידה בארגון.

## 🚀 אודות הפרויקט

הפרויקט פותח במטרה לפתור את האתגר של הכשרת נציגי שירות ומכירה בארגונים גדולים. המערכת מחליפה את הצורך בחניכה אנושית צמודה על ידי יצירת סוכן AI אינטראקטיבי המדמה לקוח, מנהל שיחה קולית מלאה ומספק משוב מיידי לנציג.

### יתרונות מרכזיים:
* **חיסכון בזמן:** צמצום משמעותי של שעות חניכה אנושית.
* **משוב אובייקטיבי:** ניתוח מדויק של רמת האמפתיה, המקצועיות ואיכות המענה.

## 🛠 טכנולוגיות

### Frontend
* **React & TypeScript:** בניית ממשק משתמש מודרני ומהיר.
* **Material UI:** עיצוב רכיבים מקצועי וחוויית משתמש (UX) חלקה.
* **Web Speech API:** מימוש זיהוי דיבור (STT) ישירות מהדפדפן.

### Backend
* **Python & FastAPI:** בניית שרת אסינכרוני בעל ביצועים גבוהים ותמיכה ב-Streaming.
* **LangChain / Google Gemini:** ניהול שיחה אינטליגנטי ועיבוד שפה טבעית (LLM).
* **ElevenLabs API:** המרת טקסט לקול (TTS) באיכות גבוהה מאוד.
* **JSON Analysis:** מנגנון ניתוח המפיק משוב מובנה לכל שיחה.

## 🏗 ארכיטקטורת המערכת

1. **Voice Interface:** המשתמש מדבר אל המערכת, הדיבור מתורגם לטקסט בזמן אמת.
2. **AI Logic:** מודל השפה מנתח את תשובת הנציג בהתאם לתרחיש שנבחר ומייצר תגובה הולמת.
3. **Voice Response:** התגובה הופכת לקול אנושי ומושמעת לנציג.
4. **Analysis Engine:** בסיום השיחה, המערכת מנתחת את כל מבנה השיחה ומפיקה דו"ח ביצועים מפורט.
