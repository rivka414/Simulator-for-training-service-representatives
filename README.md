# AI Voice Simulator - Training System

מערכת מתקדמת להכשרת נציגים המבוססת על בינה מלאכותית (AI), המאפשרת סימולציות קוליות בזמן אמת, ניתוח ביצועים אוטומטי וייעול משמעותי של תהליכי הלמידה בארגון.

## 🚀 אודות הפרויקט

הפרויקט פותח במטרה לפתור את האתגר של הכשרת נציגי שירות ומכירה. המערכת מחליפה את הצורך בחניכה אנושית צמודה על ידי יצירת סוכן AI אינטראקטיבי המדמה לקוח, מנהל שיחה קולית מלאה ומספק משוב מיידי לנציג בסיום התהליך.

### יתרונות מרכזיים:
* **חיסכון בזמן:** צמצום משמעותי של שעות חניכה אנושית.
* **סקלביליות:** אפשרות לתרגול בו-זמני של עשרות נציגים ללא הגבלה.
* **משוב אובייקטיבי:** ניתוח מדויק של רמת האמפתיה, המקצועיות ואיכות המענה מבוסס JSON.

## 🛠 טכנולוגיות

* **Backend:** Python, FastAPI, Uvicorn.
* **AI Models:** Google Gemini (LLM), ElevenLabs (TTS).
* **Frontend:** React, Material UI, Web Speech API (STT).
* **Tools:** Pydantic, Python-dotenv, Requests.

## ⚙️ הגדרות ראשוניות (Setup)

לפני הרצת הפרויקט, יש להגדיר את מפתחות ה-API הנדרשים בקובץ סביבה כדי לאפשר למערכת לתקשר עם שירותי ה-AI השונים.

1. צור קובץ בשם `.env` בתיקיית השרת (Backend).
2. העתק והדבק לתוכו את השורות הבאות והזן את המפתחות שברשותך:


GOOGLE_API_KEY=your_google_api_key_here
ELEVENLABS_API_KEY=your_elevenlabs_api_key_here
הערה: ניתן להנפיק את המפתחות בפורטלים הייעודיים של Google AI Studio ושל ElevenLabs.

# הוראות הרצה למערכת

## דרישות קדם
* **Python:** גרסה 3.10 ומעלה.
* **Node.js:** גרסה עדכנית (הכוללת את npm).

---

## 1. הרצת ה-Backend
ה-Backend מבוסס על FastAPI. בצע את השלבים הבאים כדי להפעיל אותו:

1.  **התקנת ספריות:** פתח את הטרמינל (או ה-Command Prompt) והרצ את הפקודה הבאה להתקנת התלויות הנדרשות:
    ```bash
    pip install fastapi uvicorn requests python-dotenv pydantic
    ```

2.  **הפעלת השרת:** וודא שאתה נמצא בתיקיית השורש של ה-Backend והרצ:
    ```bash
    python main.py
    ```
    *השרת יהיה זמין כברירת מחדל בכתובת:* `http://localhost:8000`

---

## 2. הרצת ה-Frontend
ה-Frontend מבוסס על React. בצע את השלבים הבאים:

1.  **ניווט לתיקייה:** בטרמינל חדש, נווט לתיקיית פרויקט ה-React:
    ```bash
    cd path/to/frontend-folder
    ```

2.  **התקנת תלויות:** התקן את כל החבילות הנדרשות לפרויקט:
    ```bash
    npm install
    ```

3.  **הפעלת הממשק:** הרצ את הפקודה הבאה כדי להפעיל את שרת הפיתוח:
    ```bash
    npm start
    ```
    *הממשק ייפתח בדפדפן בכתובת:* `http://localhost:3000`





## 🏗 ארכיטקטורת המערכת

* **FastAPI Server:** ניהול בקשות אסינכרוני (Async) המאפשר תגובה מהירה ועבודה מול מספר APIs במקביל.
* **Retry Mechanism:** לוגיקה מובנית לביצוע ניסיונות חוזרים מול שרתי ה-AI במקרים של עומס (Status 503/429).
* **Streaming Response:** שימוש בסטרימינג עבור קבצי האודיו (TTS) לשיפור מהירות התגובה למשתמש הקצה.
* **JSON Analysis:** מנגנון המאלץ את המודל להפיק פלט מובנה לצורך הצגת נתונים וסטטיסטיקות ב-Dashboard.
